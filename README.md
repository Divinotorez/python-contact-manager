# 📒 Gestion de contacts en Python

## 📌 Présentation du projet

Ce mini-projet consiste à développer une application simple en Python permettant de gérer une liste de contacts.

L'objectif est de mettre en pratique les bases de Python à travers la manipulation de données, l'utilisation de fonctions et la lecture et l'écriture dans un fichier texte.

## 🎯 Objectifs

* Ajouter de nouveaux contacts.
* Afficher la liste des contacts.
* Rechercher un contact.
* Supprimer un contact.
* Enregistrer les informations dans un fichier texte.
* Vérifier les données saisies par l'utilisateur.

## 🛠️ Technologies utilisées

* **Python** : développement de l'application.
* **Jupyter Notebook** : écriture et exécution du code.

## 📂 Contenu du dépôt

* `pro.ipynb` : notebook contenant le code Python du projet.

## 🚀 Compétences mises en pratique

* Manipulation des listes et des dictionnaires.
* Utilisation des fonctions.
* Gestion des saisies utilisateur.
* Lecture et écriture dans des fichiers texte.
* Manipulation et gestion de données.
